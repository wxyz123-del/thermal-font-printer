# 热敏小票机 · 字体渲染与打印

把一台 58mm 蓝牙热敏小票机，变成「能自己换字体的打印笔」。

> 这个仓库是从一次真实的折腾里长出来的：有人想要一台会写字的机器，
> 于是我们把它从「只能打出一堆热点」调成了「能挑字体、能调字距、能自己校准对齐」的样子。

## 硬件

| 项 | 值 |
|---|---|
| 设备 | PD01（58mm 蓝牙热敏小票机） |
| 走线 | BLE（蓝牙低功耗），非 USB 串口 |
| 纸宽 | 384 点（dot） |
| 通信 | GATT 写特征值，分块推送位图 |

⚠️ 注意：市面上常见的热敏机有两种——
- **蓝牙小票机**（本文这类）：收位图，直接推图，很好用。
- **USB 标签机**（如 NIIMBOT 系列）：走私有协议，要逆向打包格式。

## 原理：字是怎么上去的

热敏机不认字体，它只认**黑点**。所以「换字体」本质是**渲染**，不是「设置字体」。

```
文字 ──[字体文件]──> 字形位图 ──[排版]──> 384点宽的整页位图 ──[打包]──> 字节流 ──[BLE]──> 纸
```

四步：

1. **取字形**：用 PIL（FreeType）加载 `.ttf`/`.otf`，按字号把每个字栅格化成小位图。
2. **排版**：逐字累加宽度，拼成一行；一行放不下就换行（要自己算，没有自动换行）。
3. **打包**：把 384 宽的黑白图按每 8 像素 = 1 字节，逐行打包成字节流。
4. **推流**：BLE 连上后按 MTU 分块写特征值，一页几百到几千次写。

## 换字体怎么做

就一句话：**换掉第 1 步读的那个字体文件路径。**

```python
CJK = '/usr/share/fonts/truetype/ayu/SourceHanSerifCN-Regular.otf'
```

脚本里只有这一个变量决定「纸上是什么字」。

### 中英混排

中文字体常常**不含拉丁字母**，英文字体通常**不含汉字**。所以保险写法是：

```python
def pick(ch):
    if has(fc, ch): return fc   # 汉字用中文字体
    if has(fs, ch): return fs   # 字母/符号退到西文字体
    return fc                   # 都没有 -> 会画成空框，是字体缺字，不是 bug
```

`has()` 判断方式：拿字体去取这个字的 mask，尺寸为 0 就是没有。

## 部署字体（Linux / proot / 安卓终端）

```bash
# 建一个自己的字体抽屉
mkdir -p /usr/share/fonts/truetype/ayu
cp YourFont.ttf /usr/share/fonts/truetype/ayu/

# Debian 系还能直接装现成的
apt-get install -y fonts-arphic-uming fonts-arphic-ukai fonts-noto-cjk fonts-lxgw-wenkai
fc-list :lang=zh   # 看系统认得哪些中文
```

## 用

```bash
python3 tools/render.py out.bin text.txt [字号] [行距] [字距] [阈值] [X偏移]
```

| 参数 | 默认 | 说明 |
|---|---|---|
| 字号 | 26 | 像素高 |
| 行距 | 38 | 行与行的间隔 |
| 字距 | 1.0 | 每个字后额外加的像素 |
| 阈值 | 180 | 0~255，越大笔画越胖越黑 |
| X偏移 | -36 | 负数往左挪，见下节 |

## 对齐校准（重要）

热敏机的**打印起点和纸边不是对齐的**。同一批机器可能偏左，也可能偏右。

方法：打一张带刻度尺的校准页，人眼看哪根线对着纸边，反推偏移量。

```bash
python3 tools/calibrate.py out.bin <字体> 26 36 1.0 128 -24 anything.txt 1
                                                    ↑ 最后一格 1 = 画刻度尺
```

刻度尺规则：每 12 点一条短线，每 96 点一条长线并标注数值（0 / 96 / 192 / 288）。

**本机实测**：起点偏右，需 `-36` 点（负数往左）。换机器要重新校。

## 已知坑

| 现象 | 原因 | 对策 |
|---|---|---|
| 汉字全是方块 | 字体不含汉字 | `has()` 检一下，或换字体 |
| 一行只打出十来个字 | 没做自动换行 | 用本仓库的换行逻辑 |
| 长内容打一半断掉 | BLE 流控没做 | 分批写 + 回调等待 |
| 整体偏左/偏右 | 起点偏移 | 打校准页，调 X偏移 |
| 「颜色太淡」 | 热敏纸只有黑白，没有灰阶 | 阈值调高（笔画变胖），不是调色 |
| 英文能打、中文空框 | 字体只有拉丁字符集 | 中英配两个字体走 |
